# AI-Powered Resume Builder

An AI-powered resume optimization platform using Gemini, FAISS, and Retrieval-Augmented Generation (RAG).

## Features

- PDF Resume Upload
- Resume Text Extraction
- ATS Score Analysis
- Skill Gap Detection
- Resume Health Score
- FAISS-based Semantic Retrieval
- Gemini-powered Resume Optimization

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- FAISS
- Sentence Transformers
- Pandas
- NumPy

## Run

pip install -r requirements.txt

streamlit run app.py
